# SW3526 驱动(单口快充控制器)

> 职责:驱动两颗固定地址 `0x3c` 的 SW3526,读取快充协议、端口状态与 ADC 遥测。

- 寄存器手册依据:**SW3526 Register List RG012_1 v1.0**;
- 命名:沿用 SW6306 惯例 —— `STRG` = 状态/回读,`CTRG` = 控制/配置;
- 完全句柄化:`SW3526_Handle` 内含状态镜像、协程子状态与常驻 I2C 缓冲,没有全局状态对象。

## 为什么是双实例

两颗 SW3526 都使用固定地址 `0x3c`,但接在两条独立的软件 I2C 总线上
(`PA4/PA3` 与 `PA1/PA2`);因此由 `APP_Tasks_Init()` 分别创建两个句柄,可同时使用。

## 已实现的状态读取路径

| 寄存器 | 内容 |
|---|---|
| `0x06` | 协议指示(协议在线、高压状态、PD 版本、QC/FCP/SCP/PD/PPS/PE/VOOC/SFCP/AFC 类型) |
| `0x07` | 系统状态(端口开、Buck 开) |
| `0x0B` | 异常状态(OVP、OTP、短路) |
| `0x3A` + `0x3B/0x3C` | 完整 12 位 ADC:VIN 10 mV/bit、VOUT 6 mV/bit、IOUT 2.5 mA/bit |

## 使用约束

- 运行时 I/O 全部走 `Peripheral/SoftI2C` 非阻塞状态机,协程友好;
- 同一 `SW3526_Handle` 上同一时刻只允许一个顶层协程操作;不同句柄互相独立;
- 上层目前按 333 ms 周期调用 `SW3526_StatusLoad()` / `SW3526_ADCLoad()` 刷新镜像。
