# 风扇 PWM(Fan)

> 职责:把 PB9 上的 TIM1_CH1 配置为 187.5 kHz PWM,为整机散热风扇提供可调转速。

## 硬件映射

- 引脚:PB9(CH32X035 原生 `TIM1_CH1`);
- 定时器时钟:48 MHz,PSC = 0,ARR = 255 → 187.5 kHz;
- 占空比等级:CCR1 取值 0..255,与 8 位 duty 一一对应(0 = 全关;255 = 255/256≈99.6%,对风扇等同全速)。

## 主要接口

| 接口 | 说明 |
|---|---|
| `FAN_PWM_Init()` | 初始化 TIM1_CH1(初始占空比为 0,风扇保持关闭) |
| `FAN_PWM_SetDuty8(uint8_t)` | 0..255 的 8 位占空比接口,便于上层使用 |
| `FAN_PWM_SetLevel(uint16_t)` | 0..255 的原始比较值接口(与 8 位 duty 同量程) |
| `FAN_PWM_GetLevel()` / `FAN_PWM_GetFrequencyHz()` | 读取当前占空比与频率 |

## 风扇特性实测(自动调速策略依据)

以本驱动量程(占空比 0..255)实测,数据供将来的温度联动策略使用:

| 占空比 | 现象 |
|---|---|
| 0–48 | 不启动 |
| 48–72 | 能转,但有高频电流声(避免停留) |
| 80–104 | **无声运行区**;从静止启动需**从 0 直接跳到 80**,不要缓升经过 48–72 |
| 112 起 | 风噪开始变大,随占空比递增 |
| ≥200 | 仅适合在 >100 °C 时使用 |

策略要点:

- 空闲/低温默认落在 **80**(直跳,不缓升);
- 中温段从 **112** 起逐级增加;
- **>200 仅允许在温度 >100 °C 时出现**。

## 注意事项

- 目前只提供 PWM 驱动;**温度联动/自动调速策略尚未实现**,当前无任何代码修改占空比;
  UI 里的 `Fan Test` 是临时调试项,温度策略落地后删除(界面只保留"延后风扇触发点"设置)。
- 187.5 kHz 超出可闻声范围,避免风扇线圈啸叫。
