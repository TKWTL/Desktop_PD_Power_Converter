# 风扇 PWM(Fan)

> 职责:把 PB9 上的 TIM1_CH1 配置为 187.5 kHz PWM,为整机散热风扇提供可调转速。

## 硬件映射

- 引脚:PB9(CH32X035 原生 `TIM1_CH1`);
- 定时器时钟:48 MHz,PSC = 0,ARR = 255 → 187.5 kHz;
- 占空比等级:CCR1 取值 0..255,与 8 位 duty 一一对应(0 = 全关;255 = 255/256≈99.6%,对风扇等同全速)。

## 主要接口

| 接口 | 说明 |
|---|---|
| `FAN_PWM_Init()` | 初始化 TIM1_CH1(初始占空比为 0,风扇保持关闭) |
| `FAN_PWM_SetDuty8(uint8_t)` | 0..255 的 8 位占空比接口,便于上层使用 |
| `FAN_PWM_SetLevel(uint16_t)` | 0..255 的原始比较值接口(与 8 位 duty 同量程) |
| `FAN_PWM_GetLevel()` / `FAN_PWM_GetFrequencyHz()` | 读取当前占空比与频率 |

## 风扇特性实测(自动调速策略依据)

以本驱动量程(占空比 0..255)实测,数据供将来的温度联动策略使用:

| 占空比 | 现象 |
|---|---|
| 0–48 | 不启动 |
| 48–72 | 能转,但有高频电流声(避免停留) |
| 80–104 | **无声运行区**;从静止启动需**从 0 直接跳到 80**,不要缓升经过 48–72 |
| 112 起 | 风噪开始变大,随占空比递增 |
| ≥200 | 仅适合在 >100 °C 时使用 |

已实现的自动调速曲线(`APP/fan_control.c` + `thread_fan`,2026-09-14):

- 优先级:**UVP(输入 < 8 V)→ 强制 0**;GX21M15U 检测不到 → **255**(失效保底);
  其余情况走温度曲线;
- 曲线:40 °C 启动、37 °C 关闭(3 °C 迟滞),之后每升高 1 °C 占空比 **+2**,
  启动点 **80**(直跳,不缓升,即前述无声启动要求),上限 255;
- 可调"延后触发点":`FAN_Control_SetTemperatureDelay(10)` 把所有温度点整体 +10 °C
  (变为 50 °C 启动 / 47 °C 关闭),供后续 UI 设置项调用;
- 失效判定留了两道护栏:连续 3 次采样读不到才算失效,且上电前 3 s 内
  (首次采样尚未完成)不判失效——避免每次上电/偶发 NACK 就全速轰鸣。

## 注意事项

- `Fan Test` 临时调试项已删除(2026-09-14),占空比由 `thread_fan` 按上述曲线自动接管;
  唯一的驱动接口仍是 `FAN_PWM_SetDuty8()`。
- 187.5 kHz 超出可闻声范围,避免风扇线圈啸叫。
