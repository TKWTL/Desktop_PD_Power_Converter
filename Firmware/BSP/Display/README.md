# SH1107 显示 BSP

> 职责:把 u8g2 全帧缓冲可靠地刷到面板,且不阻塞协作式调度器。

## 硬件与方向

- 面板:0.78 英寸 SH1107,原生显存 80×128(TK078F288 布局);
- 逻辑界面:经 u8g2 `U8G2_R1` 旋转为 128×80 横屏(备用方向 `U8G2_R3`);
- VPP:由板卡**外部提供**,初始化序列显式发送 `0xAD, 0x8A`,保持内部 DC-DC/电荷泵关闭。

## 刷屏数据流

1. MiaoUI 在 u8g2 全帧缓冲(1280 B)上绘制;
2. `SH1107_Display_RequestFlush()` 把帧缓冲拷贝到第二块 1280 B DMA 快照并启动第 0 页;
3. 每页 = 3 字节命令 + 80 字节数据(共 16 页),页完成由 **SPI TX-DMA 完成中断**
   回调接管:释放 CS → 页号 +1 → 启动下一页;
4. 最后一页完成后回调接管收尾:若有挂起帧则立刻开始下一帧,否则执行挂起的
   对比度/休眠命令;中间动画帧会被合并(coalesce)。

## 主要接口

| 接口 | 说明 |
|---|---|
| `SH1107_Display_Init(u8g2_t *)` | 初始化面板、绑定全帧缓冲并注册 DMA 完成回调 |
| `SH1107_Display_RequestFlush()` | 请求刷新当前帧(异步,不阻塞) |
| `SH1107_Display_RequestContrast()` | 对比度设置(空闲时立即执行,否则帧末执行) |
| `SH1107_Display_RequestPowerSave()` | 屏幕休眠/唤醒 |
| `SH1107_Display_IsReady()/IsBusy()/GetFrameCount()` | 状态查询 |

## 注意事项

- 回调运行在中断上下文,只做 3 字节命令 + 启动下一页 DMA,不做长操作;
- 帧引用/挂起标志的更新会短暂关掉 DMA 中断,避免与回调竞争;
- 初始化/控制命令走 `SPI_DMA_WriteBlocking()` 短线阻塞路径。
