## 1. 准备工作

- 工具:恒温烙铁 / 热风台、助焊剂、清洗剂、万用表、可调电源、电子负载(测试用)、
  WCH-Link(烧录);
- 资料:
  - Gerber(打样):`Hardware/Manufacturing/Gerber/*.zip`(主板 / 背板 / 内面板 / 外面板,4 块都要打样);
  - 贴片坐标(仅主板 / 内面板): `Hardware/Manufacturing/CPL/*.csv`——外面板与背板为
    **无元件面板板**,不需要电子 BOM,也不需要贴片定位(坐标)文件;
  - 原理图预览:`Hardware/Preview/SCH_*.pdf`;网表:`Hardware/Preview/Netlist_*.tel`
    (同样只有主板 / 内面板有电气设计);
  - LCEDA Pro 工程:`Hardware/source/ProPrj_*.epro2`。

## 2. PCB 与电子 BOM

本项目共 **4 块 PCB**,打样时 4 块都要做;其中**外面板、背板两块只作面板/结构用,
板内没有元器件,因此既不需要电子 BOM,也不需要贴片定位(坐标)文件**。
需要 BOM 与贴装的只有主板、内面板两块:

| 板卡 | 说明 | 元件 | 电子 BOM / 贴片坐标 |
|---|---|---|---|
| 主板 | 控制 + 功率级核心板 | SMT 元件(见 CPL) | 需要(`CPL/..._主板.csv`) |
| 内面板 | 屏幕/按键面板:OLED + 阻容 + 轻触按键 | SMT 元件(见 CPL) | 需要(`CPL/..._内面板.csv`) |
| 外面板 | 前面板结构板 | 无 | **不需要** |
| 背板 | 背面板结构板 | 无 | **不需要** |

## 4. PCB 打样说明

1. 直接上传 `Hardware/Manufacturing/Gerber/*.zip` 到打样厂(**4 块板都要**,含两块无元件面板);
2. 如需 SMT:**只用主板与内面板**的 `CPL/*.csv`;外面板与背板是纯面板板,
   没有 BOM 与定位文件,按普通结构板下单即可;
3. 注意板厚/铜厚/沉金等工艺要求:以 Gerber 与工程文件为准。

![贴装完成](../Images/Assembly/04-smt-done.jpg)

## 5. 元件焊接

- 先小后大:阻容 → IC → 连接器 → 大功率器件;
- 功率路径(输入/输出)焊点需足够吃锡;电感/功率器件注意导热垫位置;
- 焊后清洗助焊剂,检查连锡/立碑。

## 6. 焊后检查(首次上电前)

- [ ] 目检:无连锡、无虚焊、极性正确;
- [ ] 万用表:各电源轨对地阻抗无短路;
- [ ] 输入端子/输出端子的极性与丝印一致。

## 7. 单板首次上电

> **新芯片(未烧录固件)第一次上电会自动进入出厂 ISP 模式**——此时不会有串口横幅
> 和 OLED 输出,属正常现象:先按 §13 用 USB + WCHISPStudio 烧录固件,再回到本节
> 做下面的检查。已烧录过固件的板子上电才会直接运行程序。

- [ ] 主板单独限流上电(建议 5 V / 小电流档先确认控制器);
- [ ] 串口(PB10/PB11 @921600)能看到启动横幅与 `[RESET] cause`;
- [ ] OLED 点亮并进入仪表盘(如已接屏);
- [ ] 温度读数合理(非 `--.-C`)。

## 8. 多块 PCB 的连接

![板间连接](../Images/Assembly/05-board-links.jpg)

<!-- 待拍:板间连接器/排线连接处特写 -->

- 按丝印/连接器键位对接,注意方向防插反;
- 板间供电线需满足整机电流;参考线束整理见 §11。

## 9. OLED 安装

![OLED 安装](../Images/Assembly/06-oled.jpg)

<!-- 待拍:屏幕安装位置、排线走向、与面板窗口的配合 -->

- 0.78″ SH1107 屏经排线接主板;注意**排线方向**与弯折半径;
- 安装后确认面板窗口无遮挡、无应力。

## 10. 风扇安装

![风扇安装](../Images/Assembly/07-fan.jpg)

<!-- 待拍:风扇固定、进出风方向标识 -->

- 确认**出风方向**朝机外;螺钉不要顶到扇叶;
- 通电验证风扇在 ≥40 °C 时会转动(可用热风辅助升温验证)。

## 11. 线束与连接器

- 输入 DC 线、输出线束固定走线槽/卡扣;避免压在功率器件与风扇上;
- 建议用绑线带固定,避免装机后拉扯焊盘。

## 12. 外壳/结构件安装

- 依次装配:内面板 → 主板/背板 → 外面板;螺钉对角均匀拧紧;
- 检查按键手感与键程(必要时调整面板开孔配合)。

## 13. 固件烧录

![ISP 连接](../Images/Assembly/08-isp-wires.jpg)

<!-- 待拍:WCH-LinkE 与调试口 GND/DIO/DCK 三线连接特写 -->

两种方式:

> **全新装配、MCU 未烧录过的板子第一次上电会自动进入出厂 ISP 模式**,不需要
> 任何菜单操作——直接按方法 1 连接电脑即可被 WCHISPStudio 识别。菜单里的
> `Reboot to ISP` 是给“已烧录固件、想再次升级”的设备用的。

**方法 1:USB 直接下载(推荐,免拆机)**

1. 电脑安装 **WCHISPStudio**;
2. 从仓库 GitHub Releases 下载固件 `.hex`(或自行构建生成);
3. USB 线连接设备 USB 口到电脑;
4. 让设备进入 ISP:
   - **新芯片/未烧录**:上电即自动进入;
   - **已烧录固件**:设备菜单选择 **`Reboot to ISP`**;
5. WCHISPStudio 识别设备后下载 `.hex`。

**方法 2:WCH-LinkE 调试下载(需打开后盖)**

1. 准备 **WCH-LinkE**;
2. 打开后盖,连接 **GND / DIO / DCK** 三根线;
3. 在 **MounRiver Studio II**(`Firmware/Desktop_PD_Power_Converter.wvproj`)
   或 **WCH-LinkUtility** 中下载。

> 用户侧说明见 [USER_MANUAL](USER_MANUAL.md) §11 固件升级。

## 14. 整机首次上电

- [ ] 空载上电:仪表盘正常、无异常复位;
- [ ] 插入 USB 设备:协议列由 `5V` 变为协议名;
- [ ] 接入 PD 电源:状态栏出现 `SPR`/`EPR`;
- [ ] 触摸/观察:温度读数上升、到 40 °C 风扇启动;
- [ ] 插拔各口:功率分配自动重新计算(见 [USER_MANUAL](USER_MANUAL.md) §7)。

## 15. 装配检查与验收

- [ ] 结构:无松动、无异响、按键正常;
- [ ] 电气:各口输出电压正常、满负载短时测试无异常;
- [ ] 热:满载 10 分钟温度稳定、风扇调速正常;
- [ ] 记录:整机序列号 / 日期 / 固件版本(建议写入机内标签)。

> 单机验收的详细测试记录模板见 [`TEST_REPORT.md`](TEST_REPORT.md)。
