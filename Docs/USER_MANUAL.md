## 1. 产品简介

桌面 PD 电源转换器把**一路大功率输入**(DC 或 USB-C PD,EPR 最高 28 V / 5 A)
转换为**四路 USB 输出**(A+C、C1、C2),内置 OLED 仪表盘、自动功率分配与主动散热。
所有快充协议由输出级控制器自动协商,无需手动配置。

## 2. 接口说明

| 位置 | 接口 | 说明 |
|---|---|---|
| 输入 | DC 座 | 直流输入(电压范围与极性以丝印/硬件说明为准) |
| 输入 | Type-C(PD) | USB-PD **Sink**:SPR 最高 20 V,EPR 最高 28 V / 5 A;建议使用 5 A E-Marker 线缆 |
| 输出 | **A + C** | SW3538 双口;仪表盘合并为一列显示 |
| 输出 | **C1** | 单口 |
| 输出 | **C2** | 单口 |
| 操作 | **NEXT**、**ENTER** | 两个轻触按键:NEXT 右侧为三角箭头,ENTER 右侧为圆形图标 |

## 3. 输入方式

### 3.1 DC 输入

- 默认按**最大预算**运行;可在仪表盘上用 **NEXT** 键以 10 W 步进下调(最小 60 W,再按回绕到 270 W);
- 输入低于 8 V(UVP)时:功率预算清零、风扇停转、仪表盘 PD 状态栏显示 `UVP`。

### 3.2 USB-C PD 输入

- 固件以 Sink 身份协商:先建 SPR 合同(最高 20 V),若电源支持则继续进入
  **EPR 28 V / 5 A**;
- 合同建立后,整机预算自动取**合同功率的 95%**(预留裕量);
- 仪表盘 PD 状态栏含义:

| 显示 | 含义 |
|---|---|
| `DC` | 未检测到 PD 连接(按 DC 输入使用) |
| `UVP` | 输入低于 8 V |
| `SPR` | PD 标准电压范围合同 |
| `EPR` | PD 3.1 扩展电压(28 V)合同 |
| `NEG` | 正在协商 |

> ⚠️ 28 V 属于 **EPR**,不是普通 PD。请确认电源与线缆都支持 EPR / 5 A;
> 首次带大功率负载前建议从小功率开始。

## 4. 各输出端口能力

| 端口 | 控制器 | 固件分配上限 | 备注 |
|---|---|---|---|
| **A + C** | SW3538(双口,共享 VOUT) | **≤140 W**(双口合计) | 仪表盘合并显示 |
| **C1** | SW3526 #1 | **≤65 W** | |
| **C2** | SW3526 #2 | **≤65 W** | |

- 表中为**控制器能力上限**;实际能跑多少功率还受整机输入预算与对端设备协商结果限制
  (见 §7 自动功率分配);
- 具体协议支持(PD/PPS/QC/FCP/SCP/PE/VOOC/AFC/SFCP 等)由对应控制器自动识别;
- 各端口实测能力表见 [`TEST_REPORT.md`](TEST_REPORT.md)。

## 5. 屏幕界面说明

### 5.1 仪表盘(开机页)

- **第 1 行**:温度(GX21M15U,0.1 °C;传感器离线显示 `--.-C`)、输入电压(整数伏)、
  功率预算(数字 + `Wmax`)、PD 输入状态(见 §3.2 表);
- **第 2–6 行**:三列遥测 —— **A+C**(SW3538 汇总)、**C1**、**C2**;
  每列依次为:端口名、输出电压、电流、功率、协议
  (未接设备显示 `NC`,接了但无快充显示 `5V`,否则显示协议名——PD 固定档显示
  `PD-FIX`、PPS 显示 `PD-PPS`;控制器离线显示 `---`);
- 端口遥测每 333 ms 刷新一次(温度 500 ms)。

### 5.2 图标菜单

按 **ENTER** 从仪表盘进入,包含:

- `-Dashboard`:返回仪表盘;
- `-Settings`:设置(休眠超时、显示对比度/背景/方向等);
- `-Burn-in Test`:烧屏测试(整屏白色,用于检查 OLED 老化);
- `-Dino Game`:小游戏(娱乐功能);
- `-About`:关于页;
- 设置页内还有 `Fan +10C`(风扇触发点延后 10 °C 的开关,见 §8)、
  `Reset Now`(立即软复位)与 `Reboot to ISP`(复位进入出厂 ISP 引导,
  固件升级用,见 §11)。
- 提示:图标主菜单上**长按 ENTER 约 1 秒**=立即休眠(关屏),见 §9。

## 6. 按键操作

面板上两个按键:**NEXT**(右侧三角箭头)与 **ENTER**(右侧圆形图标)。

| 场景 | NEXT(三角箭头) | ENTER(圆形图标) |
|---|---|---|
| 仪表盘 | 调节 DC 输入时的功率预算(10 W 步进,回绕) | 进入图标菜单 |
| 图标菜单 | 向下移动 / 长按连跳 | 进入选项 / 执行功能 |
| 设置页 | 修改当前设置值 | 确认 / 返回 |
| 烧屏测试 | —— | 任意键退出白屏 |
| 屏幕已休眠 | 按任意键唤醒 | 按任意键唤醒 |

**ENTER** 键在**松开**时生效;任意页面**长按 ENTER 约 1 秒**(键仍按住时)触发"返回":
设置页/弹窗回到上一级,仪表盘、小游戏、烧屏测试等全屏页退出回菜单,
在图标主菜单上长按则**立即休眠**(关屏)。长按后松手不会再触发一次确认。

> 唤醒需要**重新按下**一次按键(睡眠按键的松手不会误唤醒)。

## 7. 自动功率分配

固件按下面的规则把**总预算**分配给三个输出控制器:

1. **总预算来源**:
   - 输入 UVP(<8 V)→ 预算 **0 W**;
   - PD 输入 → 合同功率的 **95%**;
   - DC 输入 → 用户在仪表盘设定的值(60–270 W)。
2. **按插入顺序分配**(每 333 ms 重新计算一次):
   - 第一个接入设备的控制器获得 `min(自身上限, 预算)`;
   - 其余控制器依次获得 `min(自身上限, 剩余预算)`;
   - 拔出设备自动释放份额,后续设备会自动获得重新计算后的上限。
3. 上限值:A+C ≤140 W、C1/C2 ≤65 W(另有控制器寄存器允许范围限制)。

> **端口能力之和 ≠ 整机功率**:例如 28 V / 5 A(140 W)输入时,四口不可能同时跑到
> 各自上限;固件会按上面的规则让每个口"尽量快",这是正常行为。

## 8. 风扇工作逻辑

- **启动**:内部温度 ≥ **40 °C** 时启动;
- **停止**:温度降到 **37 °C** 以下才停止(3 °C 迟滞,避免反复启停);
- **调速**:超过启动点后每升高 1 °C 增加一档 PWM,温度越高转速越快;
- **保护**:输入 UVP 时风扇停转;温度传感器失效时风扇**全速**;
- 冷启动为静音起转点,不会出现嗡鸣的低占空比区间;
- **`Fan +10C` 设置**:打开后启动/停止温度整体上移 10 °C(50 °C 启动、47 °C
  停止),适合偏好安静的场合;关闭恢复 40/37 °C。设置立即生效,断电不保存。

## 9. 屏幕休眠与唤醒

- **自动休眠**:默认无操作 **1 分钟**关屏;可在 `-Settings` 中选择
  `No Auto Sleep` 到 30 分钟共 9 档;
- **立即休眠**:在图标主菜单上**长按 ENTER 约 1 秒**即关屏;
- **唤醒**:按键(重新按下)、输入插拔、输出功率 > 5 W 都会唤醒屏幕;
- 休眠只关屏幕,输出供电不受影响。

## 10. 保护与异常状态

| 现象 | 含义与处理 |
|---|---|
| 状态栏 `UVP` | 输入电压 < 8 V:检查输入源/线缆 |
| 某列显示 `---` | 该控制器离线(I²C 通信失败):检查连接,固件有总线自恢复 |
| 输出端口短暂掉协议 | 重新分配/重协商,设备会自动重新握手;持续异常请断电重启 |
| 整机复位 | 看门狗(IWDG)复位:请记录串口 `[RESET] cause` 输出并反馈 |

## 11. 固件升级

设备支持两种升级方式:

### 方法 1:USB 直接下载(推荐,免拆机)

1. 电脑安装 **WCHISPStudio**(沁恒官方工具);
2. 从本仓库的 **GitHub Releases** 下载固件 `.hex` 文件(也可自行用 MounRiver
   Studio II 构建 `Firmware/` 工程生成);
3. 用 USB 线把设备 USB 口连接到电脑;
4. 在设备菜单里选择 **`Reboot to ISP`**——设备复位并进入出厂 ISP 引导;
5. WCHISPStudio 识别到设备后,选择 `.hex` 点击下载。

### 方法 2:WCH-LinkE 调试下载(需要打开后盖)

1. 准备 **WCH-LinkE** 调试器;
2. 打开设备后盖,将调试器的 **GND、DIO、DCK** 三根线接到板上调试口;
3. 在 **MounRiver Studio II**(打开 `Firmware/Desktop_PD_Power_Converter.wvproj`)
   或 **WCH-LinkUtility** 中选择 CH32X035 并下载固件。

> 升级前建议记录当前版本与配置;升级后上电检查仪表盘显示与各端口功能是否正常。

## 12. 使用注意事项

- 只使用支持所需功率的**输入源与线缆**(EPR 28 V 需 5 A E-Marker 线);
- 保证进出风口通畅,不要在密闭空间满载长时间运行;
- DC 与 PD 输入**建议二选一**,同时接入的行为未验证;
- 勿在潮湿、易燃环境使用;带电时避免拉扯线缆;
- 大功率下外壳与输出口附近可能明显发热,属正常现象。

## 13. 常见问题(FAQ)

**Q1:为什么某个口功率上不去?**
A:整机预算被其它口占用。拔掉/换掉大功率设备后,333 ms 内会自动重新分配。

**Q2:为什么插上设备要等一会儿才快充?**
A:输出级控制器需要与设备完成协议握手;仪表盘协议列从 `5V` 变为协议名即握手完成。

**Q3:为什么风扇不转?**
A:低于 40 °C 不启动(开启 `Fan +10C` 后为 50 °C);输入 UVP 时风扇停转也是正常策略。
若满载仍不转,检查温度显示是否为 `--.-C`(传感器异常时风扇应全速——若全速说明是保护策略生效)。

**Q4:为什么屏幕黑屏了?**
A:进入休眠(默认 1 分钟无操作)。按任意键唤醒;可在设置里改为 No Auto Sleep。

**Q5:DC 和 PD 能同时接吗?**
A:未验证,建议二选一。

**Q6:某个端口支持哪些快充协议?**
A:由输出控制器自动识别,仪表盘协议列显示当前实际协定的协议。
